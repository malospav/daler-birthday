# Сайт-поздравление для Далера 🎉

Один файл `index.html`: гифка на фоне с самого начала, летающие фото Далера и друзей, торт со свечками, после свечей — видео-поздравление, музыка и конфетти.

## Что лежит в папке

| Файл / папка | Что это |
|---|---|
| `index.html` | сам сайт — его и открываем |
| `daler1.gif` | гифка-фон, крутится по кругу всё время |
| `photos/` | 33 фото Далера и друзей — летают на фоне |
| `music.mp3` | фоновая музыка |
| `video.mp4` | **видео-поздравление — положить сюда** (сейчас файла нет) |
| `preview.png` | картинка-превью для ссылки в Telegram/WhatsApp |
| `README.md` | эта инструкция |

## Как открыть

Двойной клик по `index.html` — откроется в браузере.

## Что происходит по шагам

1. **Загрузка** — «Сканирую Далера…», прогресс-бар, «⚠️ Обнаружен день рождения!».
2. **Главный экран** — гифка крутится фоном, летают фото друзей, глитч-надпись «ДАЛЕР», счётчик прожитых дней, кнопка **«нажми, Джан»** и убегающая **«не нажимать 😏»**.
3. **Торт** — 5 свечек, гаснут тапом или дыханием в микрофон 🎤.
4. **Видео-поздравление** — включается само, музыка плавно затухает, под видео печатается поздравление.
5. **Финал** — фейерверк и ачивка «Легенда района».

## Настройки (блок `CONFIG` в начале `<script>`)

| Настройка | Что делает |
|---|---|
| `BIRTHDAY` | Дата рождения Далера, `'ГГГГ-ММ-ДД'`. **Обязательно поменяй** — сейчас `2000-01-01`, и счётчик считает от неё. |
| `BG_GIF` | Гифка на фоне (`daler1.gif`). Пусто `''` — фона-гифки не будет. |
| `SURPRISE_SRC` | Что показывать после свечей — `video.mp4`. |
| `SURPRISE_FALLBACK` | Запасная гифка, если видео ещё нет или не проигралось (`daler1.gif`). |
| `MUSIC_SRC` | Файл музыки (`music.mp3`). |
| `MUSIC_VOLUME` | Громкость от 0 до 1 (сейчас 0.35). |
| `RESUME_MUSIC_AFTER_VIDEO` | Возвращать музыку после видео (`true` / `false`). |
| `PHOTOS` | Список фото, которые летают на фоне. Сейчас там 33 файла из `photos/`. |
| `CONGRATS` | Текст поздравления под видео. |

## Как добавить видео

Просто положи файл `video.mp4` рядом с `index.html` — сайт сам его подхватит. Пока видео нет, вместо него показывается запасная гифка, так что сайт можно смотреть уже сейчас.

## Как добавить или убрать фото

1. Положи фото в папку `photos/` (можно `photo-34.jpg`).
2. Допиши путь в список `PHOTOS` в `CONFIG`: `'photos/photo-34.jpg'`.

Если список оставить пустым `[]`, на фоне будут летать только эмодзи.

## Музыка и громкость

- Музыка включается при входе на сайт и плавно затухает, когда стартует видео.
- Кнопка 🔊 в правом верхнем углу — включить/выключить, при наведении появляется ползунок громкости.

Браузеры не разрешают включать звук без действия человека, поэтому музыка может включиться только после первого клика/тапа по странице — это нормально.

## Микрофон

Работает только на `http://localhost` или `https://`. При открытии файла двойным кликом (`file://`) браузер обычно его блокирует — тогда просто тапай по свечкам.

## Как отправить ссылку другу

1. Зайди на [netlify.com/drop](https://app.netlify.com/drop) и перетащи туда **всю папку** `daler-birthday` (вместе с `photos`, `daler1.gif`, `music.mp3`, `video.mp4`).
2. Получишь ссылку вида `https://....netlify.app` — её и отправляй.
3. В превью ссылки подтянется `preview.png` и заголовок «С Днём Рождения, Далер! 🎉».
